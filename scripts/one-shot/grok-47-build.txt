【Grok】Grok Build 可用 Grok 4.7

要点：

• Grok 4.7 已进入 Grok Build，可在模型选择器中用于更长、更难的编码与知识工作
• 新模型针对多小时任务训练，强化长上下文、过程自检与结果核验，适合让 Agent 持续推进复杂工作
• 定价与 Grok 4.6 相同：输入 $2 / 百万 token、输出 $6 / 百万 token；另有速度翻倍、价格翻倍的 Fast 版本

谁受影响：

• 在 Grok Build 里跑长时编码、Agent 工作流或专业知识任务，想从 Grok 4.6 切换的用户

怎么验：

• 更新 Grok Build 后打开模型选择器，确认能看到并选用 Grok 4.7；再用一个多步骤任务观察长任务与自检表现
