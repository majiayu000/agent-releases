# Dig one-shot style（大事件稿）

对标 @ClaudeCodeLog 空行分层 + 运维向「谁受影响 / 怎么验」。

## 文件结构

```
首条正文（零 http 链接）
---
官方：https://...
```

`---` 上方是线程根帖，下方是回复（只放官方出处）。

## 首条固定骨架

```
【标签】标题一行

要点：

• 第一条
• 第二条
• 第三条

👇 详情请看
```

硬规则：

1. 标题后、`要点：` 后、要点列表后、CTA 前都必须有空行（禁止字墙）。
2. 首条禁止任何 `http` / `https` URL。
   版本雷达根帖同此规则；官方 URL 仅出现在回复 `官方：…`。
3. 要点行首用 `•`；语义表情可放在要点词后，不要用表情代替 `•`。
4. 升级/迁移类可加：

```
谁受影响：

• …

怎么验：

• …
```

5. 保留【Claude】【Codex】【Grok】【ChatGPT】标签；不要「详见发版说明」；不要中划线堆砌。
6. 第 2 条只写：`官方：URL`（一条官方链接即可）。

## 示例

见同目录 `codex-for-oss.txt`。
